# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

Personal tech blog: Astro 7 + the AstroPaper theme, deployed to GitHub Pages (`https://dylan-kim.github.io/`). Domain terms (Post, Draft, About page, Site) are defined in `GLOSSARY.md`.

## Commands (pnpm, Node >= 22)

- `pnpm dev` — dev server at http://localhost:4321
- `pnpm build` — `astro check` (type check) + `astro build` into `dist/`
- `pnpm lint` / `pnpm format:check` / `pnpm format`
- `pnpm sync` — regenerate Astro content types after schema changes

No test suite. CI (`.github/workflows/ci.yml`, on PRs) runs lint, format:check, build — run all three before pushing. Pushing to `main` deploys (`deploy.yml`).

## Architecture

- **Config**: edit `astro-paper.config.ts` (site info, socials, feature flags). `src/config.ts` resolves it with defaults and is what code imports as `@/config` — don't edit it for settings.
- **Content**: collections in `src/content.config.ts`. Posts live at `src/content/posts/<slug>/index.md` (images colocated; files starting with `_` are ignored). The About page is `src/content/pages/about.md`. Front matter schema is defined there (`title`, `description`, `pubDatetime` required).
- **Visibility**: `src/utils/postFilter.ts` hides drafts always and, in production only, posts whose `pubDatetime` day is after the build day (in site timezone `Europe/Paris`). Dev shows all non-drafts.
- **Markdown pipeline** (`astro.config.ts`): custom rehype plugins in `src/utils/` — `rehypeFigureCaption` turns `![alt](./pic.png "Caption")` into a figure with caption; also inline TOC, table wrapper, callouts; Shiki transformers for diff/highlight/file names.
- **Customization slots**: `src/custom/{Head,BodyEnd,PostEnd}.astro` are user-owned extension points (analytics, comments, etc.) — prefer these over editing theme components.
- **Search** is disabled (`features.search: false`). Enabling Pagefind requires setting it to `"pagefind"` and re-adding the pagefind steps to the `build` script (see `copy-pagefind.mjs`).
- Dynamic OG images are generated by `src/pages/og.png.ts` (satori + sharp).
